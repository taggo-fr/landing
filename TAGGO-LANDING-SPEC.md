# TAGGO — CRÉATION DE LA LANDING PAGE OFFICIELLE

## 1. RÔLE

Tu es responsable de construire la landing page web officielle de **TAGGO**.

TAGGO est une marque de vêtements connectés utilisant un **QR code intégré au vêtement**.

Le produit principal est un T-shirt avec :

* le logo TAGGO sur le devant ;
* un QR code intégré au dos ;
* une expérience numérique accessible en scannant ce QR code.

L'objectif de cette landing page est de présenter TAGGO de manière moderne, premium, claire et mémorable, tout en restant extrêmement cohérente avec le produit réel.

# 3. OBJECTIF PRINCIPAL

La landing doit raconter une histoire unique :

**T-SHIRT → QR CODE → EXPÉRIENCE TAGGO → PERSONNALISATION → DASHBOARD → USAGES → T-SHIRT**

Il ne faut surtout pas créer plusieurs animations indépendantes.

## RÈGLE ABSOLUE

La séquence principale doit être pensée comme :

### UNE SEULE ANIMATION CONTINUE.

La caméra est le fil conducteur.

Le T-shirt, le QR et l'interface sont les différentes étapes du même mouvement.

---

# 4. INTERDICTIONS ABSOLUES

Ne fais PAS :

* plusieurs animations indépendantes ;
* un T-shirt animé séparément du QR ;
* un QR qui apparaît artificiellement ;
* un deuxième QR créé pendant la transition ;
* un T-shirt différent entre deux scènes ;
* un effet de portail ;
* un flash ;
* une explosion de particules ;
* des transitions aléatoires ;
* des rotations inutiles ;
* des zooms excessifs ;
* des animations décoratives sans fonction ;
* des éléments qui apparaissent avec des timings incohérents ;
* des effets « futuristes » qui ne correspondent pas à TAGGO ;
* des animations qui ralentissent inutilement le chargement ;
* une vidéo pré-rendue si une vraie scène 3D WebGL peut être utilisée.

Chaque mouvement doit avoir une fonction dans le storytelling.

# 27. RESPONSIVE

La landing doit être entièrement responsive.

## Desktop

Priorité principale.

La 3D doit être pleinement visible.

Résolution cible :

1920 × 1080.

Mais elle doit fonctionner correctement entre :

1280 px et 2560 px.

## Tablet

Adapter :

* caméra ;
* taille du texte ;
* espacement ;
* sections.

## Mobile

La priorité est :

**performance + lisibilité + storytelling.**

Ne jamais laisser un T-shirt ou du texte sortir de l'écran.

Si nécessaire, utiliser une version simplifiée de la séquence 3D.

# 34. ANIMATION — RÈGLE TECHNIQUE

Toutes les animations du hero doivent être pilotées par **une timeline centrale**.

Exemple conceptuel :

```text
progress = 0 → 1

0.00 — T-shirt face avant
0.10 — travelling avant
0.20 — rotation
0.30 — dos
0.40 — approche QR
0.50 — QR plein écran
0.60 — traversée QR
0.70 — page TAGGO
0.78 — personnalisation
0.84 — dashboard
0.90 — usages
0.96 — retour T-shirt
1.00 — CTA
```

Les valeurs sont indicatives.

Le principe essentiel est :

**une progression → une timeline → une caméra → un storytelling.**

Ne crée pas plusieurs systèmes d'animation indépendants qui pourraient se désynchroniser.
